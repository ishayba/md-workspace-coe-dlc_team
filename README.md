# MD Workspace 4 CoE DLC Team (v4.4.0)

> **עדכון v4.3:** תוקנה פרצת אבטחה (XSS) במנוע פענוח ה-Markdown, הוסר קובץ `app.js` שהיה קוד מת ולא נטען כלל, נוספה תמיכת PWA מלאה, ונבנתה תשתית בדיקות.

> **חדש ב-v4.4:** **CSS Studio** — עורך ויזואלי לעיצוב המסמך, עם תצוגה חיה, עריכה למצב בהיר וכהה, וספריית עיצובים של הפרויקט. ראו הסבר למטה.

## CSS Studio — עיצוב ויזואלי של מסמכים (v4.4)

1. לחצו על סמל העיפרון ליד "גלופת עיצוב" ← נפתח חלון **ניהול ועריכת תבניות עיצוב**.
2. בטאב **עריכה ויזואלית**: בחרו אלמנט (כותרת, טבלה, ציטוט, קוד, תרשים, אזור `div dir`...) מהרשימה — או פשוט **לחצו עליו בתצוגה החיה** — ושנו צבע, גופן, גודל, רווחים ומסגרת. השינוי נראה מיד, גם במסמך שמאחורי החלון.
3. מתג **בהיר / כהה** מאפשר להגדיר עיצוב נפרד לכל מצב (נשמר כ-`[data-theme="dark"] .template-<id> ...`).
4. הטאב **קוד CSS** מסונכרן דו-כיוונית עם הפאנל: אפשר לערוך בכל אחד מהם. CSS שהפאנל לא מכיר (סלקטורים אחרים, `@media`, הערות) נשמר כפי שהוא. שימו לב: עריכה ויזואלית מסדרת מחדש את ה-CSS (אלמנטים לפי סדר קבוע, הערות לסוף).
5. **ספרייה:** *ייצא קובץ* / *ייבא קובץ* (קובץ `.css` רגיל עם כותרת `mdw-theme`), ו-*שמור בספריית הפרויקט* — שומר ל-`themes/<id>.css` בתוך תיקיית הפרויקט (דורש שהאפליקציה רצה דרך `START`). לשיתוף עם הצוות: `git add themes && git commit`. ראו `themes/README.md`.
6. מסמך הדוגמה (`samples/css-studio-sample.md`) מכיל כל אלמנט שהמערכת מרנדרת כיום.
7. אזורי כיוון במסמכים: שורה שלמה `<div dir="rtl">` או `<div dir="ltr">` ... `</div>` (כל HTML אחר ממשיך להיחסם). עטיפה מפורשת תמיד גוברת על הזיהוי האוטומטי.
8. **כיוון אוטומטי:** גם בלי עטיפה, כל פסקה, כותרת, פריט, ציטוט וטבלה מיושרים לפי שפתם (רוב האותיות): עברית מימין לשמאל ואנגלית משמאל לימין. משפט עברי עם מונחים כמו API או JSON נשאר מימין לשמאל. בשדה העריכה כל שורה מתיישרת לפי שפתה.

מה שעוד לא נתמך (קישורים, תמונות, `---`, משימות ועוד) נמצא ב-[BACKLOG.md](BACKLOG.md).

## פיתוח מונחה בדיקות (TDD)

המאגר משתמש כעת ב־Node Test Runner המובנה, ללא תלות חיצונית וללא CDN.

```bash
npm test
npm run test:watch
npm run e2e   # אופציונלי: בדיקות דפדפן אמיתי (דורש Playwright מותקן אצלכם)
```

הדגשה: כל שינוי חדש צריך להתחיל בבדיקה שמתארת את ההתנהגות הרצויה, אחר כך לממש את הפתרון המינימלי, ולבסוף לנקות/לשפר את הקוד.

### מה נבדק
- **CSS Studio:** קטלוג האלמנטים, המרת CSS↔מודל ללא אובדן מידע, סניטציה, קבצי עיצוב, מסמך הדוגמה מול ה-parser האמיתי
- **`<div dir>`:** רשימה לבנה צרה ושמירה בייצוא חוזר
- **API ספריית העיצובים:** הרשאות (Host / Origin / כותרת), מגבלות גודל וזיהוי מזהים
- סנכרון גרסאות בין כל הקבצים
- חוזה ממשק המשתמש (`index.html`)
- מניעת XSS על ידי `escapeHtml`
- קבלת עמוד הבית של השרת
- טיפול בקובץ חסר
- אבטחת גישה לקבצים מחוץ למאגר

## אודות המערכת / About The System

**עברית:**
MD Workspace היא סביבת עבודה מקומית ועצמאית לחלוטין (100% Offline / Zero-CDN) ליצירה, עריכה וייצוא של מסמכי Markdown בעברית (RTL).

**English:**
MD Workspace is a completely offline, standalone PWA for creating, viewing, editing, and exporting Markdown documents with native RTL (Hebrew) support.

## תכונות מרכזיות / Key Features
* **100% Offline-First:** פעולה עצמאית ומאובטחת ללא חיבור לאינטרנט.
* **הפרדת תוכן מעיצוב:** עריכת טקסט מהירה ב-Markdown ובחירת גלופות עיצוב ארגוניות.
* **Interactive HTML Export:** ייצוא מסמך ליישום HTML עצמאי.
* **Mermaid Lite:** תמיכה מקומית בתרשימים ללא פניות ל-CDN.
* **Privacy by Design:** המידע לעולם לא עוזב את מכשיר המשתמש.
