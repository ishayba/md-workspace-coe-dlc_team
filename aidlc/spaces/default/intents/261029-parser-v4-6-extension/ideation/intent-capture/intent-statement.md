# הצהרת כוונה — v4.6.0 הרחבת ה-parser של MD Workspace

## בעיה / הזדמנות

`parseMarkdown()` — מנוע הרינדור המרכזי של MD Workspace — תומך כיום בקבוצה מוגבלת של תחביר Markdown. תשע תכונות נפוצות חסרות לחלוטין: קישורים, תמונות, קו מפריד, רשימות עם `-`/`+`, משימות, קו חוצה, רשימות מקוננות, ציטוט רב-שורתי ויישור עמודות בטבלה.

הפגמים בפועל:
- **CSS Studio** אינו יכול לעצב אלמנטים שלא מרונדרים — גלופות הצבע, הגדרות הטיפוגרפיה ועיצוב הרשימות אינם ניתנים להחלה על התכונות החסרות.
- **העורך הוויזואלי** (v4.5.0) אינו יכול לייצא ולייבא תחביר שה-parser אינו מכיר, ולכן round-trip אמין בין ויזואלי ↔ Markdown נשבר עבור תכונות אלו.
- **מסמך הדוגמה** (`samples/css-studio-sample.md`) ומסמך `SAMPLE_MD` המשמש בבדיקות אינם מכסים את מלוא מגוון האלמנטים, וכך גם כיסוי הבדיקות האוטומטיות.
- משתמשים שמדביקים תוכן סטנדרטי מ-GitHub, Notion, או Word מקבלים טקסט גולמי במקום רינדור תקין.

## מטרה

להרחיב את `parseMarkdown()` בתשע תכונות Markdown סטנדרטיות, תוך עמידה בכל עקרונות הליבה של הפרויקט (Zero-CDN, ללא תלויות חיצוניות, תמיכה ב-RTL/עברית, תאימות לאחור מלאה), ועדכון מסונכרן של CSS Studio, העורך הוויזואלי, קטלוג האלמנטים ומסמכי הדוגמה — לכל תכונה בגישת TDD.

## קריטריוני הצלחה

| # | תכונה | קריטריון הצלחה |
|---|--------|----------------|
| SC-1 | **קישורים** `[טקסט](url)` | `parseMarkdown()` מרנדר `<a>` עם `href` תקין; אימות פרוטוקול מאפשר רק `http`, `https`, `mailto` ונתיבים יחסיים; כל scheme אחר (כולל `javascript:` ו-`data:`) נדחה ומוצג כטקסט; בדיקת round-trip עוברת, כולל טקסט עברי ובדיקת `dir` |
| SC-2 | **תמונות** `![alt](src)` | `parseMarkdown()` מרנדר `<img>` עם `alt` ו-`src` תקינים; בדיקת round-trip עוברת |
| SC-3 | **קו מפריד** `---` | שורה המכילה `---`, `***` או `___` בלבד (שלושה תווים ויותר, ללא רווחים בין התווים) מרונדרת כ-`<hr>`; הצורות עם רווחים (`- - -`) מחוץ לטווח; אין פגיעה בתחביר front-matter (לא קיים בפרויקט) |
| SC-4 | **רשימות `-` ו-`+`** | פריטי רשימה עם `-` ו-`+` מרונדרים זהה ל-`*`; `*` ממשיך לעבוד |
| SC-5 | **משימות** `- [ ]` / `- [x]` | checkbox מרונדר כ-`<input type="checkbox">` עם `disabled`; סימן `[x]` מרנדר `checked`; round-trip שומר על סימון |
| SC-6 | **קו חוצה** `~~טקסט~~` | `~~...~~` מרונדר כ-`<del>`; אינו מפריע ל-`*bold*` או `` `code` `` |
| SC-7 | **רשימות מקוננות** | כניסה (הזחה של שני רווחים לרמה) מרונדרת כ-`<ul>`/`<ol>` מקונן ברקורסיה, ללא הגבלת עומק קבועה; בדיקות מכסות לפחות 3 רמות; `Tab` בעורך הוויזואלי יוצר כניסה |
| SC-8 | **ציטוט רב-שורתי** | שורות `>` עוקבות ממוזגות לבלוק `<blockquote>` יחיד; כל שורה `>` נפרדת ממשיכה ליצור blockquote עצמאי רק אם שורה ריקה מפרידה ביניהן |
| SC-9 | **יישור עמודות בטבלה** | `---:` מייצר `text-align: right`, `:---` מייצר `text-align: left`, `:---:` מייצר `text-align: center`; ברירת מחדל ללא סימן — ללא `text-align` (נשלט על ידי הגלופה) |

**קריטריון-על:** כל 131 הבדיקות הקיימות עוברות ללא שינוי לאחר הוספת כל תכונה.

**קריטריון RTL לכל SC:** לכל תכונה (SC-1 עד SC-9) לפחות בדיקה אחת עם טקסט עברי, שמאמתת גם שה-`dir` האוטומטי מוצב נכון על האלמנט ושנשמר ב-round-trip.

**קריטריון TDD לכל תכונה (6 שלבים):**
1. בדיקה ב-`test/` שנכשלת (Red)
2. מימוש מינימלי ב-`parseMarkdown()` ללא פגיעה ב-`escapeHtml` (Green)
3. אלמנט חדש ב-`ELEMENTS` של `css-studio.js` עם `probe` מתאים
4. שורה חדשה ב-`SAMPLE_MD` ובקובץ `samples/css-studio-sample.md`
5. טיפול ב-`convertChild` לייצוא "HTML חי ← MD"
6. הוספה לממיר של `md-visual.js` ולסרגל של `md-visual-ui.js`

## אילוצים

| אילוץ | פירוט |
|--------|--------|
| **Zero-CDN / 100% Offline** | אין ייבוא ספריות חיצוניות בשום שלב. כל הקוד — Vanilla JS בלבד. |
| **ללא תלויות חיצוניות** | `npm test` מריץ `node --test` ללא התקנות נוספות. אין `package-lock.json` עם תלויות ריצה. |
| **תאימות לאחור מלאה** | `escapeHtml()` אינו נגעת. כל תחביר שמרונדר כיום ממשיך להתנהג אותו דבר. לא שוברים בדיקות קיימות. |
| **RTL / עברית** | כל אלמנט חדש מקבל `dir` אוטומטי בהתאם ללוגיקת רוב האותיות הקיימת. round-trip שומר על כיוון. |
| **קובץ יחיד (index.html)** | `parseMarkdown()` חי כ-inline script ב-`index.html`. אין שינוי מבנה קבצים. |
| **TDD קפדני** | כל תכונה מתחילה בבדיקה אדומה. לא מממשים קוד ללא בדיקה קודמת. |
| **אימות פרוטוקול בקישורים** | רק `http://`, `https://`, `mailto:` ונתיבים יחסיים. כתובות `javascript:`, `data:` ואחרות — נדחות ומוצגות כטקסט. |
