## המסכים

### מסך 1 — כותרת, פאנלים סגורים (FR1.1, FR3.1, Q1)

- **ימין (תחילת השורה ב-RTL):** לוגו, שם המערכת, כותרת משנה ושדה שם המסמך, כמו היום.
- **אמצע:** "נשמר מקומית", "פתח MD", "חדש", בחירת גלופה, עריכת גלופה, "שמור MD".
- **שמאל, אחרי קו מפריד:** [נגישות] [ייצוא]. בכל אחד SVG בגודל 14px ותווית.
- **הוסרו מהסרגל:** "ייצא HTML חי", "ייצא HTML לצפייה בלבד", "ייצא ל-Word (RTL)", "הדפס / PDF". מהסרגל המשני הוסר כפתור יום/לילה.
- **הסרגל המשני:** "תבנית תוכן ▾" וכפתור הפריסה.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [ייצוא ⤓] [נגישות ♿] │ [שמור MD] [✎] [גלופה ▾] [חדש] [פתח MD] ●נשמר   [שם המסמך] MD Workspace (MD) │
├──────────────────────────────────────────────────────────────────────────────┤
│ [▥ פריסה]                                                       [תבנית תוכן ▾] │
├───────────────────────────────────────┬──────────────────────────────────────┤
│ תצוגה מקדימה (לפי הגלופה)               │ עורך                                   │
└───────────────────────────────────────┴──────────────────────────────────────┘
```

### מסך 2 — פאנל נגישות פתוח (FR2.1 עד FR2.10, FR1.6, Q2)

הפאנל נפתח מתחת לאייקון, ברוחב 320px. האייקון מודגש (`--highlight-bg` ומסגרת `--accent-primary`). כשהגדרה שונה מברירת המחדל, מופיעה נקודה כתומה.

```
┌ נגישות ─────────────────────── [×] ┐
│ ערכת צבעים                          │
│ [◐ אוטומטי][☀ יום][☾ לילה]          │
│ ניגודיות גבוהה               (○──)  │
│ גודל טקסט                           │
│ [א+]        115%         [א−]       │
│ הקראת המסמך                         │
│ [▶ הקראה] [השהיה]                   │
│ ─────────────────────────────────── │
│ איפוס הגדרות נגישות                 │
└─────────────────────────────────────┘
```

### מסך 3 — פאנל ייצוא פתוח (FR3.1 עד FR3.8, Q1 עד Q4)

רשת של שני טורים עם שישה אריחים. באריח: תג פורמט (צבע ומילה), שם ושורת הסבר. באריח ה-PDF יש גם קישור "הורדת קובץ מוכן ל-PDF".

| מיקום | אריח | תג | שורת הסבר |
|---|---|---|---|
| 1 | PDF | `PDF` (‏`--badge-pdf`) | חלון הדפסה, ואז "שמירה כ-PDF". קישור משנה: הורדת קובץ מוכן ל-PDF |
| 2 | HTML לצפייה בלבד | `HTML` (‏`--badge-html`) | קובץ אחד, בלי סקריפטים |
| 3 | HTML חי | `HTML` (‏`--badge-live`) | עם סרגל צף ומצב עריכה |
| 4 | הדפסה | `PRINT` (‏`--badge-print`) | המסמך בלבד, בלי סרגלים |
| 5 | Markdown | `MD` (‏`--badge-md`) | עטוף RTL, עם כותרת ותאריך |
| 6 | Word | `DOCX` (‏`--badge-docx`) | ‏`.docx` אמיתי, טבלאות מימין לשמאל |

### מסך 4א — מצב "מייצר קובץ…" (FR1.4, FR4.6)

הפאנל נסגר והפוקוס חזר לאייקון הייצוא. האייקון מציג סמל טעינה ואת התווית "מייצר קובץ…", עם `aria-busy="true"`.

### מסך 4ב — הקובץ נוצר (FR4.4, FR4.6, Q9)

זה המצב שבא אחרי 4א. האייקון חוזר למצב הרגיל, והפוקוס נשאר עליו. מופיעה הודעה: "✓ קובץ Word נוצר: מסמך-אפיון-תוכנה-2026-11-01.docx". שם הקובץ עטוף ב-`<bdi>` כדי שהמספרים והסיומת לא ישברו את סדר ההודעה. לשם עברי: `dir="rtl"` לכל השם, ו-`dir="ltr"` פנימי לחלק התאריך והסיומת (`2026-11-01.docx`), כדי שהנקודה לא תזוז. לשם בלי עברית: `dir="ltr"` לכל השם. ההודעה מוצגת כ-toast וגם נכתבת לאזור החי.

### מסך 5 — לילה, ניגודיות גבוהה והקראה (FR2.3, FR2.5 עד FR2.7, Q6, Q7)

- הממשק והעורך כהים. גבולות 2px בצבע הטקסט, וטקסט משני בצבע הטקסט הראשי.
- התצוגה המקדימה נשארת לבנה, לפי הגלופה.
- הפסקה שמוקראת מסומנת במסגרת `--reading-ring` (כחול כהה, 3px, וב-`.hc` ‏4px) וברקע `--reading-bg` (תכלת). הטוקנים קבועים בכל ערכה, כי התצוגה המקדימה תמיד בהירה. כך המסגרת עומדת ב-6.70:1 מול הלבן.
- ליד האייקונים מופיע כפתור "■ עצירת הקראה" בצורת גלולה (`--accent-warning-strong`), ועל אייקון הנגישות נקודה כתומה.

### מסך 6 — רוחב 400px והגדלה של 150% (NFR3, FR2.9, Q5, Q8)

- **שורה 1:** לוגו, שם המסמך (מתכווץ) ושני האייקונים בלי תוויות.
- **שורה 2 ומטה:** הכפתורים, ב-wrap.
- כותרת המשנה מוסתרת. אין גלילה אופקית.
- "דלג לתוכן" מופיע בפינה כשהוא מקבל פוקוס.
- ברוחב של עד 480px פאנל הייצוא נפרש לכל הרוחב מתחת לכותרת, באריחים בטור אחד.

### מסך 7 — מצבים מיוחדים (FR2.8, FR4.6 עד FR4.8)

ארבעה כרטיסים: מסמך ריק, שגיאה ביצירה, אריחים מושבתים בזמן ייצוא, והקראה לא נתמכת. בכל אחד ההודעה או ההסבר מופיעים בטקסט.

**הערה על תרשימי ה-ASCII:** הם מצוירים כמו שהמסך נראה, משמאל לימין. לכן "א+" מופיע משמאל ו-"א−" מימין, כמו במוקאפ הוויזואלי (ב-RTL הפקד הראשון בסדר הקריאה הוא א−, בצד ימין).
