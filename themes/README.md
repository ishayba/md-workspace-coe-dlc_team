# ספריית העיצובים של הפרויקט

כאן נשמרים קובצי עיצוב (`<id>.css`) שנוצרו ב-**CSS Studio** באמצעות הכפתור "שמור בספריית הפרויקט"
(זמין כשהאפליקציה רצה דרך `START.cmd` / `START.command`).

* כל קובץ הוא CSS רגיל, עם שורת כותרת `/* mdw-theme v1 | id: ... | name: ... */`.
* לשיתוף עם הצוות: `git add themes && git commit` (האפליקציה לא מריצה git בעצמה).
* לטעינה: בחלון ניהול התבניות — בחרו עיצוב מהרשימה ולחצו "טען", ואז "שמור תבנית" כדי להחיל אותו.
* מזהה (`id`) מורכב מ-`a-z`, `0-9`, `_`, `-` בלבד.
