דלג לרשימת הבדיקות

רשימת בדיקות ל-QA — MD Workspace v4.7.0

נגישות וייצוא. הבדיקות הידניות כאן משלימות את הבדיקות האוטומטיות, ואינן מחליפות סקירה של מומחה נגישות. הסימונים נשמרים אוטומטית בדפדפן הזה. כפתור "שמור עותק" מוריד קובץ שמכיל את הסימונים הנוכחיים.

לא ניתן לשמור אוטומטית, השתמשו ב'שמור עותק'

1. אייקונים ופאנלים (FR1)

  1. בכותרת מופיעים שני אייקונים לפי הסדר, "נגישות" ואחריו "ייצוא", ונראים בשלוש הפריסות: חלוקה, עורך בלבד ותצוגה מקדימה בלבד.
  2. Enter ו-Space על אייקון פותחים את הפאנל שלו. פתיחת פאנל אחד סוגרת את האחר.
  3. Esc, לחיצה מחוץ לפאנל וכפתור × סוגרים אותו, והפוקוס חוזר לאייקון שפתח אותו.
  4. כשמנהל התבניות או CSS Studio פתוח, הפוקוס נשאר בתוך החלון, והאייקונים זמינים אחרי שהוא נסגר.
  5. אחרי שינוי הגדרת נגישות מופיעה נקודה כתומה על האייקון, ולתווית שלו יש גם חלופה בטקסט (למשל "הוגדרו התאמות").

2. פאנל נגישות (FR2)

  1. ערכת צבעים: אוטומטי, יום ולילה. החיצים עוברים בין האפשרויות, וחץ שמאלה הוא האפשרות הבאה.
  2. מי שהיה לו ערך ישן ב-mdw_theme (יום או לילה) ממשיך לראות אותו. בלי ערך שמור, הערכה היא אוטומטי.
  3. ניגודיות גבוהה פועלת ביום ובלילה: גבולות עבים, טקסט משני בצבע הטקסט הראשי, מסגרת פוקוס בולטת, בלי אנימציות.
  4. גודל טקסט: חמש רמות (90%, 100%, 115%, 130%, 150%). בקצוות הכפתור מושבת, ולחיצה על האחוז מחזירה ל-100%.
  5. גודל הטקסט משפיע על כל המסך כולל התצוגה המקדימה. הערכה והניגודיות משפיעות על הממשק ועל העורך, והתצוגה המקדימה נשארת לפי הגלופה.
  6. הקראה: ▶ מתחילה מלמעלה, האלמנט המוקרא מודגש וגולל לתצוגה, "השהיה / המשך" עובד, Esc עוצר, וכפתור "■ עצירת הקראה" מופיע ליד האייקונים גם כשהפאנל סגור.
  7. מצבי קצה בהקראה: בלי קול עברי מוצגת הודעה וההקראה ממשיכה, בלי speechSynthesis הכפתור מושבת עם הסבר, ובמסמך ריק מוצגת הודעה.
  8. "דלג לתוכן" הוא הפקד הראשון ב-Tab, נראה רק בפוקוס, ומעביר את הפוקוס לעורך (או לתצוגה בפריסת תצוגה בלבד).
  9. "איפוס הגדרות" מחזיר ערכה אוטומטי, מבטל ניגודיות גבוהה, מחזיר 100%, עוצר הקראה ומסיר את הנקודה הכתומה.
  10. ההגדרות נשמרות אחרי טעינה מחדש של הדף. ההקראה לא נשמרת.

3. פאנל ייצוא (FR3)

  1. בפאנל שישה אריחים לפי הסדר: PDF, HTML לצפייה בלבד, HTML חי, הדפסה, Markdown ו-Word. לכל אחד תג, שם והסבר, והפאנל נסגר אחרי בחירה.
  2. אריח PDF פותח את חלון ההדפסה עם ההנחיה "שמירה כ-PDF", והקובץ שנשמר נראה תקין (עברית, טבלאות, קוד).
  3. גיבוי ה-PDF: "הורדת קובץ מוכן ל-PDF" מוריד HTML שפותח בעצמו את חלון ההדפסה בדף A4 לאורך.
  4. אריח HTML לצפייה בלבד מוריד קובץ אחד בלי סקריפטים, שנראה בדפדפן כמו התצוגה המקדימה, מימין לשמאל.
  5. אריח HTML חי מוריד קובץ עם הסרגל הצף ומצב עריכה, בלי אייקוני הנגישות והייצוא.
  6. אריח הדפסה: בתצוגה המקדימה להדפסה אין כותרת, סרגלים, פאנלים ועורך, והטבלאות, הקוד והתרשימים לא נשברים בין עמודים.
  7. אריח Markdown מוריד קובץ .md עטוף ב-<div dir="rtl" lang="he">, עם כותרת ושורת "נכון ל-".
  8. אריח Word מוריד .docx שנפתח ב-Word בלי הודעת תיקון. הפסקאות והטבלאות מימין לשמאל, שורת הכותרת של טבלה חוזרת בכל עמוד, והדף A4 לאורך.
  9. התוכן ב-Word ובקובץ ה-Markdown זהה: אותם בלוקים ואותו טקסט (כותרות, רשימות, משימות, קוד, ציטוט).
  10. שינוי ערכה, ניגודיות או גודל טקסט לא משנה את הקבצים המיוצאים.

4. כללי ייצוא (FR4)

  1. בכל קובץ מיוצא מופיעים כותרת המסמך ושורת "נכון ל-DD.MM.YYYY", ובהדפסה בראש העמוד הראשון.
  2. LRM: בשורה עברית, "3.5 Code Generation" נשאר בסדר הנכון ב-Word וב-Markdown. בלוקי קוד ותרשימים נשארים כמו שהם.
  3. שם הקובץ הוא כותרת-YYYY-MM-DD.סיומת, בלי תווים אסורים. בלי כותרת השם הוא md-workspace-YYYY-MM-DD.
  4. אם דוחים את ההורדה בדפדפן, אין הודעת שגיאה.
  5. בזמן יצירה האייקון מציג "מייצר קובץ…", הקורא מכריז על כך, ואי אפשר להתחיל ייצוא נוסף. בסיום מוצגת הודעת הצלחה.
  6. במסמך ריק בכל ששת האריחים מוצגת "המסמך ריק", לא יורד קובץ וחלון ההדפסה לא נפתח.

5. עורך ויזואלי: R-06 עד R-10 (FR5)

  1. R-06: טקסט עם עיצוב צבע שכבר קיים בעורך נשאר כמו שהוא אחרי הדבקה של טקסט אחר.
  2. R-07 (מגבלה ידועה, ראו BACKLOG): אחרי הדבקה של שורה אחת בגוף המסמך, בתא טבלה או בפריט רשימה, Ctrl/Cmd+Z מבטל את ההדבקה כולה ו-Ctrl/Cmd+Shift+Z מחזיר אותה. אחרי הדבקה של כמה שורות בגוף המסמך, Ctrl/Cmd+Z מבטל רק את החלק שאחרי השורה הראשונה, וההתנהגות הזו ידועה ומתועדת. סמנו "תקין" אם ההתנהגות תואמת את התיעוד.
  3. R-08: Ctrl/Cmd+B ו-Ctrl/Cmd+I מדגישים ומטים גם כשפריסת המקלדת עברית.
  4. R-09: בזמן הקלדה עם IME (הרכבה), Esc מסיים את ההרכבה ולא מוציא את הפוקוס מהעורך.
  5. R-10: Esc בעורך מעביר את הפוקוס לפקד גלוי ופעיל אחר, ולא נשאר בעורך.

6. קובץ הרשימה הזה (FR6)

  1. סימנו פריט, טענו את הדף מחדש, והסימון נשמר.
  2. "שמור עותק" מוריד קובץ HTML, ובפתיחתו מוצגים הסימונים.

7. קורא מסך: NVDA ו-VoiceOver (NFR1)

  1. NVDA ב-Windows (Chrome או Firefox): האייקונים מוכרזים בשמם ובמצבם (סגור או פתוח), והפאנלים נפתחים ונסגרים במקלדת.
  2. NVDA: אזור ההודעות החי מכריז על שינוי ערכה, ניגודיות וגודל טקסט, על תחילת וסיום הקראה, ועל ייצוא שהצליח או נכשל.
  3. NVDA: אריחי הייצוא מוכרזים עם שם הפורמט והסיומת, והמתג של הניגודיות מוכרז כמתג עם מצב.
  4. VoiceOver ב-macOS (Safari או Chrome): האייקונים, הפאנלים והבקרה של ערכת הצבעים מוכרזים נכון, והחיצים עוברים בין האפשרויות.
  5. VoiceOver: אזור ההודעות החי והמצב "מייצר קובץ…" מוכרזים.
  6. קורא המסך קורא את הרשימה הזו עצמה: כל פריט עם קבוצת הבחירה והשם שלו, והסיכום מוכרז.

8. ניגודיות (NFR2)

  1. ביום ובלילה, כל הטקסט בפאנלים ובאריחים קריא, והגבולות של הפקדים ושל מסגרת הפוקוס נראים בבירור.
  2. בניגודיות גבוהה, ביום ובלילה, כל הטקסט, הגבולות ומסגרת הפוקוס בולטים, כולל תגי הפורמט באריחים.

9. הגדלה ו-reflow (NFR3)

  1. ב-150% וברוחב 400px אין גלילה אופקית במסך הראשי, ואין טקסט או פקד חתוכים בכותרת ובפאנלים.
  2. ב-150%, הקלדה ולחיצה בשני העורכים מציבות את הסמן במקום הנכון, והחלונות (מנהל התבניות, CSS Studio) נשארים בתוך המסך.

10. מקלדת ופוקוס (NFR4)

  1. כל פקד חדש נגיש במקלדת ויש לו מסגרת פוקוס גלויה בעובי 3px לפחות.
  2. סדר ה-Tab הגיוני גם מימין לשמאל, ואפשר לצאת מכל פאנל ב-Tab או ב-Esc (אין מלכודת מקלדת).
  3. סדר העדיפות של Esc: חלון, אחריו פאנל, אחריו הקראה, ולבסוף העורך.
