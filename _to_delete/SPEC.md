# MD Workspace CoE DLC Team — מסמך אפיון ומפרט מערכת (v4.0.1)

> **שינויים מ-v4.0.0 → v4.0.1:** 
> 1. **שילוב מערכות התבניות:** החזרת "תבניות התוכן" (Content Templates) הטקסטואליות מגרסה 3.9 לסרגל הכלים הראשי, לצד "גלופות העיצוב" (Presentation Themes) בסרגל המשני.
> 2. **רישוי:** החלת רישיון מוסדר Creative Commons BY-NC 4.0 המונע שימוש מסחרי, תוך מתן היתר מלא לשימוש פנימי ארגוני, ועיגון זכויות היוצרים ל-B.Kinder.
> 3. **אכיפת מיתוג:** הזרקת קרדיט ורישוי באופן מובנה לתחתית תוצרי ה-HTML וה-PDF.

## 1. תקציר מנהלים וחזון המוצר
**MD Workspace 4 CoE DLC Team** היא סביבת עבודה מקומית, עצמאית לחלוטין (100% Offline / Zero-CDN / Air-Gapped) המיועדת לכתיבה, עריכה, תצוגה מקדימה, עיצוב וייצוא מסמכים ארגוניים וטכניים בעברית (RTL).
המערכת פועלת כ-Standalone PWA ללא צורך בהתקנת שרת, ללא מסדי נתונים חיצוניים וללא שליחת מידע לרשת. המערכת מתפקדת כ**מנוע הפקת מסמכים ארגוני (Document Presentation Engine)** המפריד באופן מוחלט בין תוכן המסמך לבין מעטפת העיצוב שלו.

## 2. עקרונות הליבה (Core Principles)
1. **אוטונומיה מוחלטת (Zero-CDN / 100% Offline):** אין קריאות רשת בזמן ריצה. כל העיבוד מתבצע בצד הלקוח (Client-Side).
2. **תאימות מלאה לעברית ול-RTL:** כיווניות טבעית מימין לשמאל בעורך, בתצוגה ובתוצרים.
3. **הפרדת תוכן מעיצוב (Content vs. Presentation):** תוכן המסמך נשמר תמיד כ-Markdown נקי. סגנון התצוגה נשלט דינמית על ידי "גלופת עיצוב" נבחרת.
4. **מסמך HTML חי ועצמאי (Interactive Standalone Micro-Doc):** קובץ ה-HTML המיוצא מאפשר עריכה מקומית (In-Place) ללא פתיחת האפליקציה המקורית.
5. **Privacy by Design:** המידע לעולם לא עוזב את מכשיר המשתמש.

## 3. מבנה ממשק המשתמש והפרדת התבניות

### 3.1. סרגל הכלים הראשי (Content & Actions)
* **שם ומיתוג המערכת** וניהול שם המסמך.
* **כפתורי פעולה בסיסיים:** פתח MD, חדש, שמור MD.
* **תבנית תוכן (Content Templates):** תפריט נפתח המזריק טקסט שלד (כגון PRD, HLD, סיכום פגישה) ישירות לתוך עורך ה-Markdown. מיועד לתחילת עבודה מהירה.
* **תוצרי ייצוא:** ייצא HTML חי, ייצא HTML נקי, הדפס / PDF.

### 3.2. סרגל משני (Presentation & Layout)
* **גלופת עיצוב (Theming Engine):** בורר המשנה את מעטפת ה-CSS של אזור התצוגה המקדימה ללא שינוי של קובץ ה-Markdown המקורי (למשל: "אפיון ארגוני", "טכני", "מינימליסטי").
* **ניהול גלופות:** חלון ליצירת חוקי CSS מותאמים אישית לשמירה ב-`localStorage`.
* **פריסת תצוגה (Layout Toggle):** מעבר בין חלוקה שווה, עורך מלא, או תצוגה מקדימה מלאה.
* **מצב לילה/יום (Theme Toggle).**

## 4. מפרט תוצרי הייצוא (Export Deliverables)

1. **קובץ Markdown (`.md`):** מכיל טקסט נקי בלבד, ללא מטא-דאטה של עיצוב או קרדיט.
2. **קובץ HTML חי ואוטונומי (Interactive Standalone HTML):**
   * קובץ יחיד העובד מכל דיסק מקומי.
   * מכיל **סרגל צף (Glassmorphism Pill Dock)** המאפשר לעבור למצב "עריכה" (`contenteditable="true"`).
   * כולל יכולת "לשאוב" את השינויים ולייצא חזרה קובץ `.md` מעודכן ישירות מתוך ה-HTML.
3. **קובץ HTML לצפייה בלבד (Clean View-Only HTML):** מופק ללא סרגלים צפים וללא סקריפטים, מיועד להפצה קלה לקריאה.
4. **הדפסה / PDF:** כללי `@media print` מסתירים את כל רכיבי הממשק ומפיקים פריסת A4 מהודקת עם קרדיט תחתון בלבד.

## 5. מנוע תרשימים עצמאי (Mermaid Lite Offline)
* תמיכה בבלוקי ```` ```mermaid ````.
* המערכת מייצרת מקומית גרפיקה וקטורית (Inline SVG) התומכת בתרשימי זרימה בסיסיים, ללא ספריות כבדות וללא פנייה ל-CDN. 
* קוד המקור נשמר בתוך ה-DOM (`data-mermaid-source`) כדי לאפשר שחזור מדויק בעת ייצוא ל-Markdown.
